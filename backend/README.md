# Marcela Jacon Academy - Backend API

Secure and trustable mentorship platform backend built with Node.js, Express, TypeScript, and Prisma.

## 🔒 Security Features

- **Authentication**: JWT-based authentication with refresh tokens
- **Password Security**: bcrypt with 12 rounds, strong password requirements
- **Rate Limiting**: Protection against brute force attacks
- **Input Validation**: Server-side validation using express-validator
- **Account Protection**: Automatic lockout after failed login attempts
- **Secure Headers**: Helmet.js for security headers
- **CORS**: Configured CORS for controlled access

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- PostgreSQL 14+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Copy environment variables
cp .env.example .env
# Edit .env with your configuration

# Generate Prisma client
npx prisma generate

# Run database migrations
npm run migrate
```

### Development

```bash
# Start development server with hot reload
npm run dev

# Run linter
npm run lint

# Fix linting issues
npm run lint:fix
```

### Production

```bash
# Build the project
npm run build

# Run migrations
npm run migrate:prod

# Start production server
npm start
```

### Testing

```bash
# Run tests
npm test

# Run tests in watch mode
npm test:watch

# Run security tests
npm run test:security
```

## 🔑 API Endpoints

### Authentication

- `POST /api/v1/auth/register` - Register new user
- `POST /api/v1/auth/login` - Login user
- `POST /api/v1/auth/refresh` - Refresh access token
- `POST /api/v1/auth/logout` - Logout user
- `GET /api/v1/auth/me` - Get current user info

### Health Check

- `GET /health` - Server health check

## 🛡️ Security Best Practices

### Password Requirements

- Minimum 12 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character

### Account Protection

- Maximum 5 failed login attempts
- Account locked for 30 minutes after max attempts
- Failed attempts reset on successful login

### Token Management

- Access tokens expire in 7 days
- Refresh tokens expire in 30 days
- Refresh tokens are single-use and revoked after use
- All tokens stored securely with proper indexing

## 🗄️ Database Schema

### Key Models

- **User**: Core user account with security features
- **MentorProfile**: Extended profile for mentors with verification
- **MenteeProfile**: Extended profile for mentees
- **Session**: Mentorship sessions
- **Review**: Verified reviews and ratings
- **Report**: Safety reporting system
- **RefreshToken**: Token management

See `prisma/schema.prisma` for complete schema.

## 🔧 Configuration

Environment variables (see `.env.example`):

- `NODE_ENV`: Environment (development/production)
- `PORT`: Server port (default: 3000)
- `DATABASE_URL`: PostgreSQL connection string
- `JWT_SECRET`: Secret for access tokens
- `JWT_REFRESH_SECRET`: Secret for refresh tokens
- `BCRYPT_ROUNDS`: bcrypt hashing rounds (default: 12)
- `CORS_ORIGIN`: Allowed CORS origins

## 📝 Logging

Logs are stored in the `logs/` directory:

- `combined.log`: All logs
- `error.log`: Error logs only

Logs include:
- Timestamp
- Log level
- Message
- Request details (for errors)
- Stack traces (for errors)

## 🚨 Error Handling

Standardized error responses:

```json
{
  "error": "Error message",
  "details": [] // Optional validation details
}
```

HTTP Status Codes:
- `200`: Success
- `201`: Created
- `400`: Bad Request (validation errors)
- `401`: Unauthorized
- `403`: Forbidden
- `404`: Not Found
- `423`: Locked (account locked)
- `429`: Too Many Requests (rate limited)
- `500`: Internal Server Error
